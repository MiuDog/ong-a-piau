# 尪仔標：硬幣版

以台灣尪仔標翻面玩法為靈感的 3D 字形對戰遊戲。

[開啟遊戲](https://miudog.github.io/ong-a-piau/)

- 單人對電腦，或同一裝置雙人輪流。
- 每人三枚，可輸入文字／emoji 並選字體。
- 手上優先；沒有手牌才拿起桌上自己的枚重新投擲。
- 點桌面瞄準、調整力度、投擲。命中的對手枚落地反面才收回手上。
- 奪到全部六枚，以 6：0 獲勝。

網頁程式與樣式皆在單一 `index.html`。初次載入需網路取得物理、3D 函式庫與字體；裝置字體／emoji 可能有外觀與物性差異。
