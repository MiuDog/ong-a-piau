# 字形薄片物理模型與規則說明

本階段僅建立可操作的字形物理實驗室。參考查核日期：2026-10-13。此文件規定本專案的物理近似與驗收；不宣稱重製參考遊戲的引擎。

此文件保留物理校準與規則整理步驟的契約；目前第一版亦已加入正式對局。回合、捕獲、桌面支撐、6：0勝負及電腦的現行驗收見 [game-validation.md](game-validation.md)，完整能量與介面規格見 [specification.md](specification.md)。

## 幾何、材料與近似

字形本身是有厚度的單一剛體，局部平面為 xz，正面法線為 +y。分離筆畫仍綁定同一剛體；這是遊戲中的剛性連接假設。文字與 emoji 使用選定字體及瀏覽器後備字體的 alpha 輪廓；彩色像素的 RGB 不改材料物性。

可見物件由輪廓形成平滑立體字形，像素方塊只供隱藏碰撞近似。面積空洞不能被可見矩形背板填滿。物理網格與輪廓不完全重合，接觸精度受網格限制；這是明示的離散誤差，不是像素方塊就是展示物件。

設材料密度 ρ、共同厚度 t、方格邊長 s、格內平均 alpha 為 aᵢ。超過共同門檻的格保留，其質量 mᵢ = ρts²aᵢ。aᵢ 表示有效覆蓋體積比例，不是材料密度。保留格的碰撞體仍為完整 s×t×s 方盒，格內質量用均勻分布近似；邊緣抗鋸齒與被門檻捨棄的細筆畫造成近似誤差。

基礎物理校準採相同尺寸框、厚度、密度、摩擦、彈性與耗散。字形擬合進尺寸框，故比較是相同展示尺度，不是相同字體點數。後續若加入攻防平衡，必須另外標明哪些參數是遊戲規則；不能把人為調整說成純粹的形狀物理定律。字體／瀏覽器／emoji 字型可改取樣結果；需要跨裝置一致的正式對局時另處理資產固定問題。

## 三項物理量

### 1. 質量：相同衝量的平移反應

M = Σmᵢ，重心 c = Σ(mᵢpᵢ)/M。質量 M 直接指定剛體 mass；相同外加衝量 J 導致 Δv = J/M。密度為共同材質參數；面積較大通常較重，但相同自由落體高度的撞擊不是固定衝量實驗，不能把重量直接當成勝率。

### 2. 支撐穩定性：翻越支撐邊的重力能障

平躺時，以保留碰撞格四角的凸包作為整片剛體支撐多邊形。空心形狀內部不需要虛構碰撞材質，仍可由外部接觸點形成凸支撐區。

對每條支撐邊，計算平面重心到邊的垂直距離 d，取最小值 d_min。重心高度 h = t/2，最弱邊的準靜態重力能障為 E = Mg(√(d_min²+h²)−h)，單位焦耳。它描述固定支撐邊、無滑動與無分離時把重心抬過支點所需的重力位能增加；不是引擎額外施加的抗翻力或動態翻面門檻。

重心及碰撞接觸位置直接參與求解，E 是其可解釋摘要。不把字框中心到重心距離當成穩定性；偏心本身不保證較易翻。遠離最弱邊的打擊、滑動、碰撞次序與動態角動量都會改結果。

### 3. 力臂／慣量：相同位置與衝量的旋轉反應

設相對重心的格中心 rᵢ = (xᵢ,0,zᵢ)。重心座標下慣量張量為：

Ixx = Σmᵢ[zᵢ²+(s²+t²)/12]；Izz = Σmᵢ[xᵢ²+(s²+t²)/12]。

Iyy = Σmᵢ[xᵢ²+zᵢ²+s²/6]；Ixz = Izx = −Σmᵢxᵢzᵢ；Ixy = Iyz = 0。

張量含每格自身方盒慣量，不能只把方格當質點。求 xz 平面的主軸後，在主軸座標儲存對角慣量；碰撞格、展示物件與初始姿態需使用互逆旋轉，確保世界中的字形與重心沒有被錯轉。覆寫引擎預設包圍盒慣量時，同步反慣量、世界慣量及求解用慣量。

在相對重心世界位移 r 施加衝量 J：ΔL = r×J，Δω = I_world⁻¹ΔL。對垂直向上單位衝量，主軸中的靈敏度 A = √[(r_z/Ix)²+(r_x/Iz)²]，單位 (rad/s)/(N·s)。它隨施力點改變；重心施力不產生旋轉，邊緣施力通常有較大力矩，但較遠也可能伴隨較大慣量，不能只按長度判定容易翻。

## 停止與翻面

只在薄片與桌面真實接觸、線速度及角速度各自低於門檻並維持安靜時間後判面；兩種速度不能相加，因單位不同。仍在移動、空中最高點、側立／明顯傾斜均不能判為成功。超時表示未定，不能硬判輸贏。

以世界法線 n = q(0,1,0) 判斷；n_y > 0.85 為正面，n_y < −0.85 為背面，其餘未定。翻面由實際姿態判斷，不能用隨機數、衝量大小或文字分數代替。測試球必須與薄片產生引擎接觸並傳遞動量。

## 獨立驗收與檔案保護

[tests/physics.cjs](../tests/physics.cjs) 為測試作者維護的保護檔案，實作者只能讀取與執行。預期值來自解析矩形、兩個不重疊矩形組成的不對稱 L 形及標準剛體公式，不取產品算出的慣量作為預期答案。

必要集合：解析質量／重心／慣量不變量；平移與反對稱慣性耦合；密度倍率；同剛體不同力臂；alpha 覆蓋率；桌面正背側與空中／移動拒判；真實測試球碰撞。高解析輪廓的外觀另由畫面驗證，不用物理測試代替視覺檢查。

## 下一步：有界攻防分配

此處處理攻防取捨。已確認邊緣命中可有加成，但只有最終背面朝上才算成功；不得強制落回正面，也不得為了淘汰直接改成背面。邊緣加成的接觸偵測與能量上限另行驗收，不用進攻預算測試代替。

### 輸入定義

「筆畫密度」指固定字形框內的有效覆蓋率 c = Σaᵢ / grid² = M/(ρtS²)，不是改變材料密度 ρ；S 是字形框邊長。沿用碰撞取樣保留格的 alpha，使攻防資料與剛體幾何來源一致。c 限定在 [0,1]，文字與 emoji 均依 alpha 面積計算，顏色及字元編碼不給額外加成。

空白、完全被門檻剔除的字形不生成剛體、不允許發射。防禦式計算遇到零質量或非有限數值時，回傳有限的零發射預算；不能以除以極小常數製造任意大速度。

### 分配及物理作用

進攻份額 O = 0.75−0.5c；防守份額 D = 0.25+0.5c。兩者各在 [0.25,0.75] 且 O+D=1。O 與前節翻轉靈敏度 A 不同：O 是遊戲分配；A 是選定力臂的物理響應。

防守份額的附加作用是角阻尼 dω = 0.08+0.24D，在 [0.14,0.26] 之內，直接設定薄片的 angularDamping。高覆蓋率因此增加既有質量抵抗，也增加旋轉耗散；其質量及慣量仍完全遵循前節公式，禁止為配合分數改寫質量或慣量。角阻尼同時作用於進攻時的自身旋轉，不是僅在被攻擊時暗改求解。它不改重力能障，也不保證任意形狀都較難翻。

這項角阻尼調整是刻意加入的遊戲平衡，不是從字形材料自然推導的定律。物理校準與攻防試驗的差異應可見，不能把新角阻尼混稱為固定共同材質。

發射力度 p 限定在 [0,1]。進攻可用動能 E_budget = 0.8 O p² 焦耳。由剛體質量 M 計算發射衝量：

J = min(√(2 M E_budget), 6M, 1.2)；v = J/M；E_actual = J²/(2M)。

因此速度不超過 6 m/s，衝量不超過 1.2 N·s，實際可用能量不超過分配預算。上式 E_actual 作為本次拋擲的總能量上限；v 是若全部作為平移動能時的速度上限。起始發射在薄片重心施加水平方向衝量，不憑空附加初始旋轉；之後偏心接觸的旋轉仍由引擎透過 r×J 與真實慣量求得。

本步演示為所選字形的單體拋擲。高度 h = min(0.6, E_actual/(2Mg))，起始重心高度為 t/2+0.003+h；扣除 Mg h 後，把剩餘能量分配為 +x 平移動能。實際速度為 √[2(E_actual−Mgh)/M]。因此不能讓高質量字形在預算之外取得更多落下能量；共同的 0.003 m 接觸間隙不算額外拋擲高度。初始旋轉若日後加入，也需計入 ½ωᵀIω。

### 可驗證範圍與限制

密字必定取得較低進攻預算與較高防守耗散，這是可驗證的單調分配。質量非常小時速度上限會先限制實際動能，因此「稀疏字每次實際撞擊都更強」並不成立：在有限速度下 M→0 必然使動能趨近零。展示應區分可用預算與實際注入動能，不能只顯示一個較高攻擊分數。

較低發射能量也不保證每次接觸衝量較小；質量、形狀、施力點、支撐邊、姿態及撞擊時序共同決定結果。O+D 固定不是所有字體、字元、對位與玩家操作的勝率平衡證明。正式宣稱「沒有全方位最強字」前，需要實際對位模擬及測試資料；本步只消除以覆蓋率同時提高攻防預算的設計。

本步僅以當前字形剛體的真實拋擲展示相同力度下的能量、速度與耗散差異，尚不是字形攻防對局或勝率證據。原固定測試球繼續作防守校準；它不能作為字形進攻能力的證據。下一個可操作驗證才是向固定基準薄片發射並比較接觸反應。本步不包含雙人回合、捕獲或淘汰規則。

### 最小介面與獨立驗收

balanceProfile(model) 回傳 coverage、offense、defense、angularDamping，依序表示有效覆蓋率、進攻份額、防守份額及實際角阻尼；launchBudget(model,power) 回傳 energyBudget、impulse、speed、energy，依序表示分配預算、限制後衝量、全動能速度上限及本次可用總能量。launch() 使用目前模型及 throw-power 控制項，實際生成前述高度與重心衝量。

[tests/balance.cjs](../tests/balance.cjs) 為另一個保護測試，原 [tests/physics.cjs](../tests/physics.cjs) 不得為攻防功能而改寫預期。新測試由解析矩形覆蓋率檢查單調分配、alpha、能量／速度／衝量上限，涵蓋空白、無效質量與 emoji；再檢查真實剛體質量、碰撞格、角阻尼、發射速度、零起始自旋及 Mg h+½Mv²。最後在無接觸的空中模擬固定時間，確認角阻尼確實改變旋轉耗散，不能只修改顯示值。

## 邊緣撬起加成與最終落面

這是使用者指定的遊戲規則，額外注入受限能量；不是宣稱自然碰撞的受力會因面積減少而自動放大。現在只接在固定測試球對字形的真實碰撞上，尚非完整字形對局規則。

edgeProfile(model,point) 的 point 是主軸局部座標、以重心為原點的接觸力臂。轉回取樣座標後尋找最近碰撞格；四鄰格至少缺一格才視作邊緣。以 R = 0.16+s/2 的局部圓形足跡，累加中心落在圓內之有效格面積，得到 f = clamp(Σaᵢs²/(πR²),0.05,1)。這是接觸附近的筆畫覆蓋代理量，不是引擎量測出的真實接觸斑面積。

邊緣倍率 G = 1+2(1−f)，內部 G = 1，所以倍率在 [1,2.9]。相同足跡下，稀疏邊緣取得較大加成。低於 0.5 m/s 的法向相對速度不啟動加成；只處理本次測試球，且一次測試最多補充一次向上衝量，不因多個像素方盒的重複接觸而重複注入。

令世界向上單位向量為 n、接觸世界力臂為 r、u = r×n、剛體已有速度為 v、ω。額外向上衝量 j 引起的完整動能變化為：

ΔK = b j + ½k j²，其中 b = v·n + ω·u，k = 1/M + uᵀI_world⁻¹u。

先由 ΔK = 0.12 J 解正根 j_energy，再取 j = min(0.3, j_energy, 0.25 M V_impact (G−1))。實作使用局部主軸計算等價式。此上限包含既有速度的交叉項與轉動能；只計 j²/(2M) 會漏掉偏心旋轉及交叉項，不能作驗收依據。

tests/balance.cjs 另外保護三組邊緣行為：解析稀疏／密集邊緣與內部分類；任意初始旋轉和平移下，量測補充衝量前後總動能及拒絕重複施加；真實測試球確實觸發一次加成，以及保留助推記錄後最終正面接觸桌面仍不判成功。這些測試不要求某個字或某一次撞擊必定翻面，也不允許為滿足測試而強制設定最終姿態。
