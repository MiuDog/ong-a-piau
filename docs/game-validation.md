# 平板字形對局：現行驗收契約

本文件以使用者最新更正為準：每枚一個字素，平板正反面保留彩色字形；高彈性、低初始旋轉，近邊緣按壓依像素覆蓋率決定強度。投出枚每次真正離地再落地可重新產生震波，25% 機率為大範圍爆炸。圓形場地所有高度都向內小反彈，完整薄片不得飛出；顯示區正方形、固定正交視角偏離垂直 15°。玩家及 CPU 都從場內向內出手，四邊手勢速度影響初速；碰撞音效、爆炸及捕獲效果皆不能替代物理與捕獲規則。

## 玩法不變量

1. 開局恰有六個唯一 id，每位玩家各持三枚。body 為 null 表示手中，否則為桌面或飛行中的物理薄片；總枚數不能增減。
2. 有手中枚必須先投手中枚；手中清空才可撿自己的桌面枚。不可選對手枚，不可在模擬中重複投擲。
3. 本次攻方透過真實碰撞或接觸連鎖影響的對手枚，只有最終穩定面向與本次出手前穩定面向相反、已停止且具有傳至桌面的真實支撐時，才被捕獲到攻方手中。正轉背、背轉正都成立；同面平面內旋轉、曾彈起、曾翻面又翻回、空中瞬停、側立及超時未定均不能直接判捕獲。
4. 自己投出的枚不因自己的動作被捕獲。同手可奪多枚；先完成捕獲及勝利判定再換人。只有六比零勝利，五比一繼續。
5. 捕獲保留 id、文字、字體、形狀模型、質量、重心、慣量與字形衍生物性，只轉移所有權與辨識顏色；舊桌面剛體及展示物件需移除。
6. CPU 遵守相同選枚、發射與結算流程，不直接指定翻面、捕獲或勝負。重開清理舊剛體、待處理接觸及舊 CPU 行動；過期回呼不能污染新局。

## 平板形狀、質量與碰撞

原字形 alpha 取樣仍決定佔據格、孔洞、重心及水平主慣量。遊戲覆蓋率 c=Σalpha/grid²，規範化質量 M=0.18+0.12c kg。每格質量、原主慣量及平面穩定參考按 M/M_raw 一致縮放，保留原重心、格位、字體和 alpha，不能原地修改實驗室原模型。這是明示的遊戲材質平衡，不宣稱各字形仍有相同材料密度。

正式對局只使用規範化平板模型，不能保留 curve 或非零 lift。可見物體為平滑字形擠出薄片；真正碰撞亦為平板，上下表面位於重心相對 y=±thickness/2。不能只恢復平板外觀而保留翹曲碰撞或慣量。

每枚設定以 Intl.Segmenter 的 grapheme 計數，必須恰一字素；AB 或兩個 emoji 拒絕，👩‍🚀 等組合 emoji 保留完整。設定失敗不能破壞現行對局，須顯示錯誤。正面及背面材質都使用原彩色 canvas 紋理，背面另加 0x98c4df 色調辨識；兩面材質均須真覆蓋幾何，不能僅讓 emoji 正面有色。

相同連續欄區間可跨相鄰列合併矩形方盒，不能跨空列或填洞。驗收以獨立環形、斷行、變寬、單格及完整矩形遮罩逐格重建聯集，拒絕漏格、重疊或填洞；再由真正引擎形狀的角點、偏移與旋轉重建原格，核對垂直厚度。可見字形全部三角形須被材料群組覆蓋。

## 字形物性、仰角與甩動速度

O=0.75−0.5c，D=0.25+0.5c。角阻尼為 0.08+0.24D；每枚高彈性基準 e=0.72+0.2O/0.75，摩擦 f=0.3+0.2D。桌面材質的反彈與摩擦為 1，因此高速碰撞時薄片對桌面的係數為該枚的 e、f；兩枚互撞係數由引擎取 ea×eb、fa×fb。實驗室 defaultContactMaterial.restitution 仍為 0.1。

為避免高反彈造成低速接地數值微彈，在真正接觸方程送入求解器前，僅將相對法向速率小於 0.5m/s 的對局接觸反彈暫降：地面接觸 0.22、雙片接觸 0.22²。材質與字形基準不改；快速飛片撞靜止受擊片仍依高相對速度保留高彈性，不能按受擊片自身速度錯降反彈。新增真接觸案例量測求解前入射速度及求解後方程係數，並保留真落地強彈、雙片動量交換及自然停妥驗收。

字形基準預算 E=1.05×0.30×g+4O，出生高度 h=0.9+0.2O。令 P=Mgh、R=E−P，基準平移能量 L=min(0.75R,18M,0.72/M)。實際甩速 s 以每秒戰場高度計，速度倍率 q=0.8+0.4clamp(s,0,3)，介於 0.8 與 2。發射速度為 min(12,q√(2L/M))，旋轉能量僅保留 0.09(R−L)，失去的旋轉能量不挪給平移。預設及 CPU 的 s=0.5，故 q=1。

完整實際能量以 MgΔh+½Mv²+½ωᵀIω 記帳，等於 P+q²L+0.09(R−L)。目前規範化字形不會撞到額外速度限制，仍驗證速度不超過 12m/s、平移動量不超過 2.4N·s。同甩速下實際能量隨 c 嚴格下降，質量與耗散隨 c 上升；這不保證所有字形對局勝率相等。測試在 s=0、0.5、3 各使用五個解析覆蓋率檢查單調性，不能只驗 UI 分數或名目預算。

唯一物理滑桿為 15° 至 65° 的仰角，預設 35°。真正初速度 vy=v sinθ，水平速度為 v cosθ；同字形與甩速的能量及出生高度不能隨角度改變。測試量測 15°、35°、65° 三個真實速度方向及完整能量。

下緣握持點以原字框 (x=0,z=size/2) 定義，轉為重心主軸座標後取 r×v，角速方向依 I⁻¹(r×v)，再縮放到旋轉能量 0.09(R−L)。測試獨立重算前版角速度，確認本版恰為其 30%，並保留相同覆蓋率、不同分布字形的不同空中角速，以及 Iω 與 r×v 同向。這是發射器能量分配，不宣稱為單次自由偏心衝量自然決定的唯一平移／旋轉比例。

反彈驗收沒有 setter 或滑桿介入：相同水平輪廓、不同 alpha 覆蓋率的字形取得不同的衍生材質，真實落地回彈及雙片分離速度必須有相應差別。雙片案例暫停重力與轉動以隔離一維碰撞，完成後恢复重力；雙方都必須透過接觸交換動量。

## 高彈性碰撞與較強邊緣按壓

近邊緣包含邊界像素中心及筆畫內側兩格，距最近邊界中心距離為 d，proximity=max(0,1−d/(2.5step))，超過兩格不加成。將受擊枚真像素中心依兩枚剛體姿態投影到攻方原字框，以 alpha 加權求 coveredArea/targetArea；不把整個包圍盒當成筆畫。strength=proximity×(0.08+0.92×(1−coverage))，G=1+2strength。解析同心矩形驗證面積比、內側兩格衰減及深中心不觸發，並量測覆蓋越多真正衝量越弱。

入射速度門檻為 0.2m/s，衝量保留一般版兩倍。n 為世界向上方向、r 為接觸力臂，b=v·n+ω·(r×n)，k=1/M+(r×n)ᵀI⁻¹(r×n)，額外預算 Eedge=1.2O_attacker/0.75×strength。

先算 jbase=min(0.8,(−b+√(b²+2kEedge))/k,0.8M_victim Vimpact(G−1))，實際衝量 J=2jbase，完整動能增量為 bJ+½kJ²，上限為 4Eedge+2max(0,−b)jbase。不能忽略施力前平移及旋轉造成的交叉項。每枚受擊枚每次投擲最多接受一次，最多 1.6N·s；己方也可被彈起，但仍不能被自己的出手捕獲。這是有界遊戲助推，不是被動守恆碰撞；多枚連鎖不能把單枚預算誤稱為整回合上限。

測試從相同初始速度、角速度及力臂，獨立計算基準衝量，核對真正 Δv、IΔω 恰有兩倍回應及完整動能；0.19m/s 不觸發、0.3m/s 可觸發。位置、四元數及所有權不可由施力函式直接更改。

真正 collide 回呼只保存接觸雙方、局部力臂與入射速度；postStep 才依求解後實際速度施加助推。真碰撞驗收保留時序、非零角速、含交叉項的完整能量上限及後續不重複加成。材質反彈與邊緣助推分開驗收。

## 真離地後重新落地的範圍震波

只有本手投出枚真正向下接觸地面、入射速率至少 0.2m/s 時，才在 postStep 產生震波。同一次連續接地的多像素回呼不重施；只有 postStep 已無投出枚與地面接觸，且其真 AABB 下緣高於 0.03m，才重新開放下一次落地。震源保存求解前真接觸的水平座標。作用半徑 R=2.2+0.8O，範圍採其他場上枚重心到震源的三維距離 d，手中枚及 d≥R 不受影響。己方也可被推動，但不因此成為己方可捕獲對象。

共享額外預算 Ewave=min(2.4,0.12Msource Vimpact²O)，每枚權重 w=(1−d/R)²，各得 Ewave×w/Σw。衝量向外及向上，施力點落在最靠近震源的真佔據像素下緣；用施力前真速度及角速計算 b、k，取 J=min(0.65,(−b+√(b²+2kEallocated))/k,0.35Mtarget Vimpact(1−d/R))。每枚完整 ΔKE=bJ+½kJ²，不得把無交叉項的靜止公式套到移動薄片；全部受波枚的 ΔKE 總和不超過共享預算。

兩組驗收分別隔離觸發生命週期及施力公式：真實落地案例檢查 collide 時尚未出波、postStep 才出波、連續接地去重、真離地重置，以及第二次落地重新抽選為爆炸；解析小矩形案例量測靜止與已有平移／角速時的真正動能增量、每枚及共享上限、近遠衰減、水平及垂直界外排除與手中排除。施力不可直接修改位置、四元數或所有權。己方已有穩定正面基準、受波後背面真停妥，仍不能被自己捕獲。

邊緣助推與震波是兩個獨立的有界施力來源：前者每枚受擊枚每手一次，後者每次真正重新落地一次，皆限當前模擬中的本手。既有真碰撞案例按純向上的邊緣衝量分開計數，避免把合法向外震波誤認為第二次邊緣助推；兩者的能量驗收各自保留。

每次合法重新落地只抽一次 Math.random()<0.25；不合法接觸及同次接地的重入不抽。普通分支使用上述參數；爆炸半徑改為 2.5R，共享預算改為 min(16,0.9Msource Vimpact²O)，衝量上限為 2.4N·s，距離衰減速度上限改為 1.25Mtarget Vimpact(1−d/Rexplosion)。權重及完整動能二次式不變，不能把每枚上限誤當可對每枚重複使用的總預算。

一般驗收固定非爆炸分支，並以 finally 恢復 Math.random。爆炸案例固定 0.25 與 0.249 分別驗普通及爆炸門檻，涵蓋靜止和已有平移／角速的薄片；原普通圈外、爆炸圈內的枚必須只有爆炸時受力。重複觸發不能增加任何随机呼叫、能量或替換第一次結果。Three 圖形物件建立也可能使用隨機 UUID，因此不把所有視覺隨機呼叫都算成爆炸抽選。爆炸不能直接改姿態或所有權，己方翻面免疫、手中排除及相對翻面規則均維持。

## 四邊向內甩動、固定正交視角與圓形場地

真正瀏覽器 mouse/pointer 驗證四邊各 25% 外圍起拖、有限方向箭頭與瞄準點、短拖取消、向外取消、向內放開出手及 CPU 回合鎖定。須沿起點至板中心方向前進至少 12px，且世界瞄準點比起點更靠圓心；中央起拖、單點與 Enter 均不投擲，介面沒有投擲按鈕。無阻擋候選下，真正水平初速度必須對齊 startWorld→aim，不可四邊都沿同一預設方向。拖曳不改仰角；甩速由整段路徑長除以戰場高度與整段耗時，包含放開位置及等待時間。相同路徑快、慢兩次真滑鼠手勢須有相同瞄準點及符合 q 比例的真初速。

箭頭現在表示出手方向與瞄準點，不再承諾無碰撞拋物線恰落在該點。最高甩速的原射程可能超過場地直徑；限制出生位置而保留能量、仰角與高度後，不能同時保留舊精準落點契約。真瀏覽器仍驗瞄準點未被偷偷改動、向內真初速度、有效軌跡及放開後收起箭頭。

場地顯示區為正方形，不超過 80vh 或視窗寬；角度與選枚控制放在上方或下方。相機必須真正為 OrthographicCamera，世界視線為 (0,−cos15°,−sin15°)；眼睛固定於 (0,40,40tan15°)，對準地面原點 (0,0,0)。投影半高固定 10.2m，半寬為 10.2×aspect，不追蹤薄片、瞄準或特效。正方形 resize 維持同幅面及姿態。其餘力度、反彈、難度滑桿及舊實驗室入口不向玩家開放；校準 API 仍供原保護測試使用。

固定相機回歸在相同 viewport 比較完整 matrixWorld 與 projectionMatrix：真投擲偏心落點、真落地普通震波與爆炸、薄片散到遠方、真正停妥結算，全程都須完全不變。另一組真瀏覽器 resize 改變視窗比例，要求顯示區仍正方形、投影依上述公式計算，眼睛、原點及 15° 姿態保持不變。

圓形場地半徑 9m，保留 64 段高 1.2m、材質反彈 0.15 的低圓周，另在每次 postStep 對所有高度執行完整形狀邊界約束。依真像素角點求旋轉安全外接半徑 radius，重心安全半徑為 9−radius−0.08。超出時將水平位置投影回安全圓；只有向外法向速度 vn>0 才變為 −0.15vn，原向內或純切向速度不反射。切向及垂直速度、垂直位置、四元數與角速度保持；動能不可增加，須清除舊支撐快取並喚醒。這是明示的場地約束，不能宣稱只是低圓周自然碰撞。

獨立 postStep 約束在 active 且 ready 時也須有效，避免逾時換手後仍運動的枚飛走。驗收從真碰撞方盒的角點重建完整世界形狀，檢查地面、高空 80m/s 與爆炸擊飛後全部留在 9m 圓內。安全圓可能先於低圓周接觸反射，因此不要求每次均產生 Cannon rim collide；仍要求真步進的向內小反彈，而非只改顯示座標。任何邊界作用不得直接改所有權或指定翻面。

## 碰撞音效

開始或外圍手勢解鎖 WebAudio；真碰撞相對速率至少 0.4m/s 才播放，同一無向剛體配對 80ms 內去重，音量不超過 0.12，聲音節點具有限生命週期。音效關閉或不支援時不改物理、回合及所有權。驗收使用可觀察的 AudioContext stub 核對解鎖、閾值、對稱配對去重、冷卻恢復及真多像素碰撞只響一次；另由真滑鼠手勢確認瀏覽器解鎖，不做聲音波形 golden 比對。

玩家及 CPU 共用發射器：瞄準必須有限且半徑不超過 7.5m，指定方向不可為零。沿期望方向從瞄準點回推出生位置；若原起點超出安全圓，以該射線與安全圓交點截斷。每個候選都須滿足 spawnXZ·velocityXZ<0，並完整位於場內；保留原速度、仰角、高度及旋轉能量。驗收在稀疏與密字形、最高甩速、15°／35°／65° 下核對玩家與 CPU 真出生形狀、向內速度與完整預算。

發射前仍沿有限方向尋找 AABB 不與其他桌面枚重疊的位置，排除即將拿起的同枚；各候選共用原能量與高度。非法瞄準、零方向或完全受阻時，必須在刪除剛體、清除旗標、開始回合或建立逾時計時器前拒絕。保留手中及桌面重投兩種受阻原子拒絕斷言。

## 真實時間截止與回合生命週期

每次成功投擲才設定原生 12000ms 計時器，並保存 Date.now()+12000 截止值；拒投不得建立計時器。正常結算、逾時結算、重開及離開皆清除 handle 與截止值。原生回呼核對 epoch、turn、thrownId、active 及 simulating 狀態，舊回呼不得切換新一手、新局或離開後的頁面。

動畫也以 Date.now() 對截止值補判，不能再用經截斷的 frame delta 累計當逾時依據。到期呼叫原強制結算路徑，僅捕獲已具合法相對翻面、真命中與真支撐的停止敵枚；仍在運動、空中或不具可靠基準的枚留在場上並換手。低幀率及背景頁的瀏覽器仍可能延遲執行回呼，恢復執行時必須依真時間立即判斷。

回歸攔截原生 setTimeout／clearTimeout 並控制 Date.now，finally 恢復原函式。驗證真 12 秒設定、到期僅換一手、運動中背面敌枚不捕獲、動畫截止與原生回呼競爭不重複换手、重開／離開舊回呼隔離及正常停妥清理。低幀率案例只給 0.0001 秒動畫 delta，但將真時間推至截止，仍必須完成換手。

## 捕獲特效

金色 type=capture 特效只能在捕獲條件全部成立且結算選中該枚後產生，先保留原位置再移除物理薄片。碰撞、暫時翻面或尚未停止時不播放捕獲成功特效。青色 type=shock 環只表示普通落地震波，生命週期為 0.6 秒；橘色 type=explosion 環與碎光表示爆炸，生命週期為 0.9 秒。兩者都不能代替捕獲結果。

真碰撞到捕獲案例驗證結算前沒有 capture 效果、捕獲後恰一個 capture 效果，更新時有 elapsed 生命週期，結束後清理視覺物件。震波另驗更新、到期移出場景及重開清理。兩種特效更新及清理均不得改變牌 id、所有權或物理物件集合；未成立捕獲的排除案例必須仍無 capture 效果。

## 相對於出手前的穩定面向

目前將「跟之前反面」解讀為相對本次出手前的面向。發射前、喚醒或移除原桌面枚之前，保存各枚 faceBeforeThrow：只有真實接地支撐且已停止、法向 y>0.85 才為 +1，y<−0.85 才為 −1，其他情況為 0。手中枚及初始空中、移動、側立枚沒有可靠基準。

最後捕獲仍須是命中的敵方，且初始基準為 ±1，最終真實穩定面向恰為基準的負值。不能把未知基準當成正面，也不能單憑最終看到背面就捕獲。

新增兩組必要回歸：四種前後面向組合覆蓋正轉背、背轉正及兩種同面不變；同面案例另旋轉字樣 180°，確認平面內倒置不是翻到另一面。三種缺基準案例分別為初始空中、移動及真接地側立，之後即使命中並背面停妥，也不能捕獲或播成功特效。

既有真碰撞、動態／空中排除、多枚捕獲、六比零及支撐移除 fixture 先取得真實停止的初始面向，再安排相反最終面向。測試只安排位置與姿態，仍必須透過真正 world.step 取得接觸、停止及捕獲流程；不直接改 faceBeforeThrow 為預期答案。這是按新規則更新情境，不移除原所有權、物性保留或支撐斷言。
## 睡眠支撐與驗收界限

引擎可省略睡眠物件的接觸方程。只有曾沿真實接觸連到桌面的薄片，才可保存支撐路徑的剛體、位置及姿態。沿用時該枚須仍睡眠，所有路徑剛體仍在本局、姿態未變且速度低於停止門檻；從未接地的空中枚不可取得快取。
