# 平板字形對局：現行驗收契約

本文件以使用者最新更正為準：字形恢復平板，邊緣助推採上一版衝量的六倍，玩家只調整發射仰角。其他物理參數由字形導出。先前翹曲幾何與可調反彈／力度的要求已被取代，不再作為現行驗收標準。

## 玩法不變量

1. 開局恰有六個唯一 id，每位玩家各持三枚。body 為 null 表示手中，否則為桌面或飛行中的物理薄片；總枚數不能增減。
2. 有手中枚必須先投手中枚；手中清空才可撿自己的桌面枚。不可選對手枚，不可在模擬中重複投擲。
3. 本次攻方透過真實碰撞或接觸連鎖影響的對手枚，只有最終背面朝上、已停止且具有傳至桌面的真實支撐時，才被捕獲到攻方手中。曾彈起、曾翻面、空中瞬停、侧立、超時未定均不能直接判捕獲。
4. 自己投出的枚不因自己的動作被捕獲。同手可奪多枚；先完成捕獲及勝利判定再換人。只有六比零勝利，五比一繼續。
5. 捕獲保留 id、文字、字體、形狀模型、質量、重心、慣量與字形衍生物性，只轉移所有權與辨識顏色；舊桌面剛體及展示物件需移除。
6. CPU 遵守相同選枚、發射與結算流程，不直接指定翻面、捕獲或勝負。重開清理舊剛體、待處理接觸及舊 CPU 行動；過期回呼不能污染新局。

## 平板形狀、質量與碰撞

原字形 alpha 取樣仍決定佔據格、孔洞、重心及水平主慣量。遊戲覆蓋率 c=Σalpha/grid²，規範化質量 M=0.18+0.12c kg。每格質量、原主慣量及平面穩定參考按 M/M_raw 一致縮放，保留原重心、格位、字體和 alpha，不能原地修改實驗室原模型。這是明示的遊戲材質平衡，不宣稱各字形仍有相同材料密度。

正式對局只使用規範化平板模型，不能保留 curve 或非零 lift。可見物體為平滑字形擠出薄片；真正碰撞亦為平板，上下表面位於重心相對 y=±thickness/2。不能只恢復平板外觀而保留翹曲碰撞或慣量。

相同連續欄區間可跨相鄰列合併矩形方盒，不能跨空列或填洞。驗收以獨立環形、斷行、變寬、單格及完整矩形遮罩逐格重建聯集，拒絕漏格、重疊或填洞；再由真正引擎形狀的角點、偏移與旋轉重建原格，核對垂直厚度。可見字形全部三角形須被材料群組覆蓋。

## 只有仰角可調，其他參數由字形推導

O=0.75−0.5c，D=0.25+0.5c。角阻尼為 0.08+0.24D；每枚材質反彈 e=0.45+0.25O/0.75，摩擦 f=0.3+0.2D。桌面／牆材質的反彈與摩擦為 1，因此薄片對桌面的實際係數為該枚的 e、f；兩枚互撞係數由引擎取 ea×eb、fa×fb。實驗室 defaultContactMaterial.restitution 仍為 0.1。

發射總能量 E=1.05×0.30×g+4O，出生高度 h=0.9+0.2O。扣除 Mgh 得到 R，平移分配 Klinear=min(0.75R,18M,0.72/M)，其餘作 Kspin。完整能量以 MgΔh+½Mv²+½ωᵀIω 記帳；實際速度不能超過 6m/s，平移動量不能超過 1.2N·s。E 隨 c 嚴格下降，質量與耗散隨 c 上升；這不保證所有字形對局勝率相等。

玩家唯一可調物理參數為 15° 至 65° 的仰角，預設 35°。真正初速度 vy=v sinθ，水平速度為 v cosθ，能量及出生高度不能隨角度或拖曳距離改變。測試量測 15°、35°、65° 三個真實速度方向及完整能量；另用五個解析覆蓋率確認質量與实际能量的單調效果。

下緣握持點以原字框 (x=0,z=size/2) 定義，轉為重心主軸座標後取 r×v，角速方向依 I⁻¹(r×v)，再縮放到 Kspin。這是發射器的能量分配；不宣稱為單次自由偏心衝量自然決定的唯一平移／旋轉比例。相同覆蓋率、不同分布的兩個字形必須有不同空中角速，且實際 Iω 與 r×v 同向。

反彈驗收沒有 setter 或滑桿介入：相同水平輪廓、不同 alpha 覆蓋率的字形取得不同的衍生材質，真實落地回彈及雙片分離速度必須有相應差別。雙片案例暫停重力與轉動以隔離一維碰撞，完成後恢复重力；雙方都必須透過接觸交換動量。

## 六倍邊緣助推

保留舊版邊緣面積判定及入射門檻，先從相同求解後狀態計算舊衝量 j：

- n 為世界向上方向，r 為接觸力臂；b=v·n+ω·(r×n)。
- k=1/M+(r×n)ᵀI⁻¹(r×n)，Eold=1.2O_attacker/0.75。
- j=min(0.8, (−b+√(b²+2kEold))/k, 0.8M_victim Vimpact(G−1))。
- 實際施加 J=6j，故向上衝量最多 4.8N·s。同一敵枚每次投擲仍最多一次。

六倍衝量不等於六倍能量。完整增量 ΔK(J)=bJ+½kJ²，因此 ΔK(6j)=36ΔK(j)−30bj，其上界為 36Eold+30max(0,−b)j。這是額外注入能量的遊戲助推，不是被動守恆碰撞；多枚連鎖時亦不能把單枚上限當作整回合總上限。

測試在相同初始速度、角速度、質量及接觸力臂下，獨立計算舊 j，量測真正 Δv 與 IΔω 均精確符合六倍衝量；核對完整動能、不直接修改位置／四元數、同枚不重複施力，也不能直接改所有權。

真正 collide 回呼只保存接觸雙方、局部力臂與入射速度。postStep 在本步求解後施加助推，使用此刻線速度及角速度重算能量。真實碰撞回歸確認回呼內尚未提前施力、步進後產生角速，後續物理模擬確實把受擊枚拋離桌面，且再碰撞不能重複加成。空中拋起仍不等於捕獲。

## 拖曳、出生與邊界

瀏覽器真正 mouse/pointer 事件驗證：從桌面底部向上拖曳顯示有限箭頭與預測落點，短拖取消不生成薄片，放開才真正投擲；拖曳只瞄準，不改選定仰角或以距離偷偷更改能量。CPU 回合禁止玩家偷投。無碰撞、無空氣阻力的拋物線終點須與預測落點相符，不宣稱預測碰撞後最後停點。

介面不再有力度、反彈或難度控制；只有角度滑桿。舊實驗室 API 留給受保護校準測試，沒有玩家可進入的控制入口。

發射前沿有限方向尋找牆內且 AABB 不與其他桌面枚重疊的出生位置，排除即將拿起的同枚。各候選共用字形衍生能量及高度。無可用位置時，必須在刪除原剛體、清除旗標或開始回合前拒絕；手中與桌面重投兩種情境均驗證物件集合、持有權、姿態與回合不變。成功出生則驗證不重疊、整枚在牆內及完整能量。

高處邊界以真正飛行薄片撞牆驗收，不能靠坐標截斷；撞牆不捕獲、不複製、不改所有權。較強助推可能延長等待，最終仍須真實停止，不能因等待時間到就指定翻面。

## 睡眠支撐與驗收界限

引擎可省略睡眠物件的接觸方程。只有曾沿真實接觸連到桌面的薄片，才可保存支撐路徑的剛體、位置及姿態。沿用時該枚須仍睡眠，所有路徑剛體仍在本局、姿態未變且速度低於停止門檻；從未接地的空中枚不可取得快取。

新投擲或捕獲移除支撐時，清除剩餘薄片快取並喚醒。驗收涵蓋接觸被省略仍可判停止、移至空中即失效、睡眠疊放支撐、捕獲下層後上層喚醒與失效。fixture 依真 AABB 安放，必須取得真接觸；不偽造支撐紀錄。
