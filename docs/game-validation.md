# 平板字形對局：現行驗收契約

本文件以使用者最新更正為準：字形維持平板，恢復一般碰撞與一般邊緣助推，只保留初始高拋。戰場全寬、正上方正交視角、無牆及無水平邊界，只能由底部拖曳出手，捕獲成立後才播特效。玩家只調整發射仰角，其他物理參數由字形導出。先前翹曲、六倍助推及可調反彈／力度均已被取代。

## 玩法不變量

1. 開局恰有六個唯一 id，每位玩家各持三枚。body 為 null 表示手中，否則為桌面或飛行中的物理薄片；總枚數不能增減。
2. 有手中枚必須先投手中枚；手中清空才可撿自己的桌面枚。不可選對手枚，不可在模擬中重複投擲。
3. 本次攻方透過真實碰撞或接觸連鎖影響的對手枚，只有最終穩定面向與本次出手前穩定面向相反、已停止且具有傳至桌面的真實支撐時，才被捕獲到攻方手中。正轉背、背轉正都成立；同面平面內旋轉、曾彈起、曾翻面又翻回、空中瞬停、側立及超時未定均不能直接判捕獲。
4. 自己投出的枚不因自己的動作被捕獲。同手可奪多枚；先完成捕獲及勝利判定再換人。只有六比零勝利，五比一繼續。
5. 捕獲保留 id、文字、字體、形狀模型、質量、重心、慣量與字形衍生物性，只轉移所有權與辨識顏色；舊桌面剛體及展示物件需移除。
6. CPU 遵守相同選枚、發射與結算流程，不直接指定翻面、捕獲或勝負。重開清理舊剛體、待處理接觸及舊 CPU 行動；過期回呼不能污染新局。

## 平板形狀、質量與碰撞

原字形 alpha 取樣仍決定佔據格、孔洞、重心及水平主慣量。遊戲覆蓋率 c=Σalpha/grid²，規範化質量 M=0.18+0.12c kg。每格質量、原主慣量及平面穩定參考按 M/M_raw 一致縮放，保留原重心、格位、字體和 alpha，不能原地修改實驗室原模型。這是明示的遊戲材質平衡，不宣稱各字形仍有相同材料密度。

正式對局只使用規範化平板模型，不能保留 curve 或非零 lift。可見物體為平滑字形擠出薄片；真正碰撞亦為平板，上下表面位於重心相對 y=±thickness/2。不能只恢復平板外觀而保留翹曲碰撞或慣量。

相同連續欄區間可跨相鄰列合併矩形方盒，不能跨空列或填洞。驗收以獨立環形、斷行、變寬、單格及完整矩形遮罩逐格重建聯集，拒絕漏格、重疊或填洞；再由真正引擎形狀的角點、偏移與旋轉重建原格，核對垂直厚度。可見字形全部三角形須被材料群組覆蓋。

## 只有仰角可調，其他參數由字形推導

O=0.75−0.5c，D=0.25+0.5c。角阻尼為 0.08+0.24D；每枚材質反彈 e=0.22+0.12O/0.75，摩擦 f=0.3+0.2D。桌面材質的反彈與摩擦為 1，因此薄片對桌面的實際係數為該枚的 e、f；兩枚互撞係數由引擎取 ea×eb、fa×fb。實驗室 defaultContactMaterial.restitution 仍為 0.1。

發射總能量 E=1.05×0.30×g+4O，出生高度 h=0.9+0.2O。扣除 Mgh 得到 R，平移分配 Klinear=min(0.75R,18M,0.72/M)，其餘作 Kspin。完整能量以 MgΔh+½Mv²+½ωᵀIω 記帳；實際速度不能超過 6m/s，平移動量不能超過 1.2N·s。E 隨 c 嚴格下降，質量與耗散隨 c 上升；這不保證所有字形對局勝率相等。

玩家唯一可調物理參數為 15° 至 65° 的仰角，預設 35°。真正初速度 vy=v sinθ，水平速度為 v cosθ，能量及出生高度不能隨角度或拖曳距離改變。測試量測 15°、35°、65° 三個真實速度方向及完整能量；另用五個解析覆蓋率確認質量與实际能量的單調效果。

下緣握持點以原字框 (x=0,z=size/2) 定義，轉為重心主軸座標後取 r×v，角速方向依 I⁻¹(r×v)，再縮放到 Kspin。這是發射器的能量分配；不宣稱為單次自由偏心衝量自然決定的唯一平移／旋轉比例。相同覆蓋率、不同分布的兩個字形必須有不同空中角速，且實際 Iω 與 r×v 同向。

反彈驗收沒有 setter 或滑桿介入：相同水平輪廓、不同 alpha 覆蓋率的字形取得不同的衍生材質，真實落地回彈及雙片分離速度必須有相應差別。雙片案例暫停重力與轉動以隔離一維碰撞，完成後恢复重力；雙方都必須透過接觸交換動量。

## 一般碰撞及有限邊緣助推

恢復原一般邊緣面積判定及入射門檻，不再放大六倍。n 為世界向上方向、r 為接觸力臂，b=v·n+ω·(r×n)，k=1/M+(r×n)ᵀI⁻¹(r×n)，單枚額外預算 Eedge=1.2O_attacker/0.75。

實際衝量 j=min(0.8,(−b+√(b²+2kEedge))/k,0.8M_victim Vimpact(G−1))，完整動能增量為 bj+½kj²。每枚敵方每次投擲最多接受一次；最多 0.8N·s。這是有界遊戲助推，不是被動守恆碰撞；多枚連鎖不能把單枚預算誤稱為整回合上限。

測試從相同初始速度、角速度及力臂，獨立計算一般衝量，核對真正 Δv、IΔω 與完整動能，拒絕殘留六倍倍率；位置、四元數及所有權不可由施力函式直接更改。

真正 collide 回呼只保存接觸雙方、局部力臂與入射速度；postStep 才依求解後實際速度施加助推。真碰撞驗收保留時序、非零角速、完整能量上限及後續不重複加成。只在發射時提高初始高度，不能把普通碰撞改為每次大幅拋飛。

## 底部拖曳、全寬正上視角與無邊界地面

真正瀏覽器 mouse/pointer 事件驗證底部拖曳、有限箭頭與預測落點、短拖取消、放開出手及 CPU 回合鎖定。非底部單點不改瞄準也不出手；Enter 不投擲，介面沒有投擲按鈕。拖曳只瞄準，不更改仰角或用距離改變能量。無碰撞、無空氣阻力的拋物線終點須與預測落點相符，並非預測碰撞後最後停點。

戰場至少使用驗收視窗 90% 寬度，角度與選枚控制放在上方或下方。相機必須真正為 OrthographicCamera，世界視線為 (0,−1,0)，不能只用接近俯視的透視相機。其餘力度、反彈、難度控制及舊實驗室入口不向玩家開放；校準 API 仍供原保護測試使用。

物理世界只有無限地面，沒有隱形牆。薄片須能自然越過舊桌面範圍而不被夾限、淘汰或改所有權。瞄準 (100,−100) 的投擲必須成立，出生位置仍在遠方，真拋物線終點也須抵達該點，避免只刪牆卻殘留瞄準／出生座標限制。

發射前仍沿有限方向尋找 AABB 不與其他桌面枚重疊的位置，排除即將拿起的同枚；各候選共用原能量與高度。完全受阻時，必須在刪除剛體、清除旗標或開始回合前拒絕。原「所有候選在牆外」fixture 已無效，改以實際既有薄片占據出生高度及全部候選方向；保留手中及桌面重投兩種原子拒絕斷言。

## 捕獲特效

特效只能在捕獲條件全部成立且結算選中該枚後產生，先保留原位置再移除物理薄片。碰撞、暫時翻面或尚未停止時不播放捕獲成功特效。

真碰撞到捕獲案例驗證結算前 effects 為空、捕獲後恰一個視覺效果，更新時有 elapsed 生命週期，結束後清理視覺物件。特效更新及清理不得改變牌 id、所有權或物理物件集合；未成立捕獲的排除案例必須仍無成功特效。

## 相對於出手前的穩定面向

目前將「跟之前反面」解讀為相對本次出手前的面向。發射前、喚醒或移除原桌面枚之前，保存各枚 faceBeforeThrow：只有真實接地支撐且已停止、法向 y>0.85 才為 +1，y<−0.85 才為 −1，其他情況為 0。手中枚及初始空中、移動、側立枚沒有可靠基準。

最後捕獲仍須是命中的敵方，且初始基準為 ±1，最終真實穩定面向恰為基準的負值。不能把未知基準當成正面，也不能單憑最終看到背面就捕獲。

新增兩組必要回歸：四種前後面向組合覆蓋正轉背、背轉正及兩種同面不變；同面案例另旋轉字樣 180°，確認平面內倒置不是翻到另一面。三種缺基準案例分別為初始空中、移動及真接地側立，之後即使命中並背面停妥，也不能捕獲或播成功特效。

既有真碰撞、動態／空中排除、多枚捕獲、六比零及支撐移除 fixture 先取得真實停止的初始面向，再安排相反最終面向。測試只安排位置與姿態，仍必須透過真正 world.step 取得接觸、停止及捕獲流程；不直接改 faceBeforeThrow 為預期答案。這是按新規則更新情境，不移除原所有權、物性保留或支撐斷言。
## 睡眠支撐與驗收界限

引擎可省略睡眠物件的接觸方程。只有曾沿真實接觸連到桌面的薄片，才可保存支撐路徑的剛體、位置及姿態。沿用時該枚須仍睡眠，所有路徑剛體仍在本局、姿態未變且速度低於停止門檻；從未接地的空中枚不可取得快取。

新投擲或捕獲移除支撐時，清除剩餘薄片快取並喚醒。驗收涵蓋接觸被省略仍可判停止、移至空中即失效、睡眠疊放支撐、捕獲下層後上層喚醒與失效。fixture 依真 AABB 安放，必須取得真接觸；不偽造支撐紀錄。
