# 可玩第一版：對局驗收契約

本文件只定義已確認玩法及必要驗收。原有字形質量／慣量、攻防預算及邊緣助推的保護測試持續適用；不能為了讓對局通過而改其预期。

## 本次互動擴充的驗收要求

本次新增要求已完成整合驗收：遊戲反彈係數可調整，且同時影響薄片對桌面與薄片互撞；從畫面底部向上拖曳時顯示箭頭及有限的預測落點，放開才投出；過短拖曳取消，電腦回合禁止玩家偷投；投擲起始高度提高，空中角運動依字形重心／主慣量及偏心施力方向改變。這些要求不改變捕獲條件、手中優先、所有權保留或六比零勝利。

反彈驗收必須以相同初始条件比較低、高係數的真實落地及雙片碰撞速度，不能只核對介面數字或材料欄位。複合字形可有多個接觸點，不要求整體每次都完全等於理想一維解析反彈係數；但較高設定必須產生清楚可測的較強反彈，且攻方及受方都參與真實動量交換。

提高出生高度必須明示新增的重力位能預算。平移、旋轉及高度仍由同一完整能量記帳，速度／衝量上限適用於實際平移部分；不得將未使用的 UI 預算當成實际動能，或為維持旧總預算而暗中降低已承諾的出生高度。實驗室原公式及原保護測試不因遊戲高拋而改動。

## 不變量

1. 開局恰有六枚不同 id 的薄片，兩位玩家各持三枚；每枚只存在於一個位置。body 為 null 表示手中，非 null 表示桌面或正在飛行。
2. 持有數永遠是手中枚數加桌面枚數，不以桌面數或手牌數單獨判勝。一般回合不得創造、複製或遺失薄片。
3. 有手中枚時只能投擲手中枚；沒有手中枚時才可撿起自己的桌面枚。不能選對手的枚，也不能在模擬中再次投擲。
4. 捕獲只作用於本次攻方實際碰撞或接觸連鎖影響的對手枚。自己投出的枚即使背面落地，也不能被自己的動作捕獲。
5. 對手枚只有在最終背面朝上、具有傳至桌面的真實接觸支撐且已停止後，才轉移到攻方手中。支撐可直接接觸桌面，或經其他已停止的薄片傳到桌面；只有薄片相互接觸、整組仍在空中不算支撐。空中瞬停、側立、仍在移動、超時未定及最後正面朝上均不算捕獲。不能因為曾彈起或曾朝下而判成功。
6. 同次投擲可捕獲多枚。捕獲保留 id、文字、字體、形狀模型、質量、重心、慣量與攻防物性，只轉移所有權和辨識顏色，並移除被捕獲枚的桌面剛體／展示物件。
7. 只有六比零可勝利；五比一不能結束。先處理本回合所有捕獲及勝利，再切換下一位玩家，避免捕獲判給下一位。
8. 電腦必須遵守相同選枚和力度限制，透過相同真實拋擲／接觸／結算路徑行動；不能直接指定翻面、修改所有權或抽籤決勝。
9. 重開對局會清除舊桌面物件與待執行電腦行動。舊非同步字體載入、舊計時器或舊回合回呼不得改写新對局。

真實捕獲案例安排對手以背面躺地，再讓攻方薄片真正接觸它，驗證碰撞標記、支撐、捕獲與下次重投。這能隔離生命周期錯誤，但不宣稱任意自然拋擲都能翻面；從開局到終局的實際操作與玩法可行性仍需整體試玩驗證。

## 碰撞合併優化的保護界限

遊戲物理先把相鄰格合併為矩形：相同連續欄區間只跨相鄰列延伸，不能跨空列、不同寬度或空洞。平板模型使用方盒；翹曲模型再把矩形切為最多 3×3 格的凸薄片。質量與主慣量取原格 alpha 分布、遊戲材質一致縮放及下述翹曲高度積分，不能改用整字包圍盒近似慣量。可見字形不因碰撞分片變為方塊。

驗收使用獨立環形、斷行、變寬、單格及完整矩形遮罩，逐格重建矩形聯集並拒絕重疊、填洞與漏格；完整矩形的合併清單應只有一塊，確保合併有實際作用。另從真正 CANNON 方盒或凸薄片的八個角點、偏移及旋轉，反推其水平格聯集；每個水平角點必須具有相差原厚度的上下表面，避免只有合併清單正確、建立剛體卻錯位。

原「盒數等於格數」驗收只適用於一格一盒的舊實作，已由測試作者替換為更直接的「實際佔據區完全等同原字形」驗收；捕獲後身份、模型、質量及主慣量保留的要求不變。

遊戲投擲固定由 h=0.9m 出生，總能量為 E = 0.9×0.30×g + 4 O p²。這個共同基準額外涵蓋最大規範化質量的出生位能，是新增高拋要求的明示遊戲預算。扣除 Mgh 後得到 R，平移分配 K_linear=min(0.75R,18M,0.72/M)，其餘為 K_spin。測試從實際剛體量測 MgΔh、½Mv²及½ωᵀIω，確認三者合計等於 E，且速度不超過 6 m/s、平移動量不超過 1.2 N·s。速度／衝量上限僅限制平移，不再截斷包含出生位能的整個預算；實驗室原公式保持不變。

## 遊戲材質的攻防單調分配

為讓「密字防守较強、進攻較弱」作用於實際投擲，而不只停留在未使用的能量預算，遊戲模型採用明示的材質平衡。覆蓋率 c 仍由 Σalpha/grid² 取得，不從規範化後質量反推固定材料密度。

balanceGameModel(raw) 指定 M = 0.18+0.12c kg，再以 k = M/M_raw 一致縮放每格質量、三個主慣量及重力能障。重心、主軸角度、字體、輪廓、格位、alpha、支撐邊與尺寸保持不變。原始實驗室模型、原格與原慣量不得原地修改；實驗室仍使用原共同材料密度。這是遊戲的有效材質調整，不是所有字形都仍具有同一材料密度的物理宣稱。

O = 0.75−0.5c，故相同力度 p 下，遊戲總能量 E = 0.9×0.30×g + (3−2c)p²。當 c 在 [0,1]，M 在 [0.18,0.30]。共同高拋基準與 c 無關，因此 p>0 時總能量仍隨覆蓋率嚴格下降；p=0 時總能量相同，但固定高度的位能與剩餘動能分配不同。平移能量的兩個上限直接保證 v≤6 及 Mv≤1.2，多出的動能分配到旋轉，不能仍使用舊版「全部能量轉平移也不會超速」的證明。

這使相同 p>0 的實際總投擲能量隨 c 嚴格下降；質量與既有防守角阻尼則上升。測試以單格到完整方框的五個解析覆蓋率，檢查原模型不變、縮放比例、COM／形狀不變，並從真正投擲剛體的高度、平移與旋轉讀回能量，驗證單調效果。完整對局勝率仍受字形支撐、慣量分布、命中點與玩家操作影響；單調分配不等於所有字元的勝率相等。

遊戲邊緣助推的額外能量上限為 1.2×O_attacker/0.75 J，同一對手枚每次投擲最多接受一次。仍以完整的既有平移／角速交叉項解出能量上限衝量，再取 min(0.8, J_energy, 0.8M_victim V_impact(G−1))；实际向上衝量不超過 0.8 N·s。上限隨攻方筆畫密度增加而下降。

這是額外注入能量的遊戲助推，與起始投擲能量分開計算，並非被動碰撞自然守恆。上限以每個受擊敵枚計，連鎖影響多枚時，該次投擲的助推總量可能高於單枚上限；不能將 1.2 J 誤稱為整回合總上限。足夠的理論總預算也不保證某次撞擊必定跨越重力能障，仍需真實接觸與最終面向判定。

測試以相同敵方形狀與既有速度，量測真遊戲接觸處理前後的完整動能差，確認上下限與一次性，並確認位置及四元數未被直接修改；不允許助推直接更改所有權或最後朝向。實驗室的 0.12 J 助推上限與原保護測試不變。

## 真實接觸時序與桌面邊界

遊戲碰撞回呼保存真實接觸的雙方、局部力臂與入射法向速度；引擎完成本步接觸求解後才處理助推。額外動能上限依此刻剛體的完整線速度及角速度重新計算，不能使用求解前的速度計算後再盲目追加。這避免同一步支撐求解立即抵消遊戲助推；仍不保證每次都翻面。

回歸透過真正兩枚薄片接觸，確認碰撞回呼中尚未施加助推、步進完成後產生非零角速變化、完整動能增量有界，且後续接觸不能重複加成。量測只包裹真正的 applyImpulse，不更改其參數；並核對施力不直接改位置、四元數或所有權。

重開案例保存一筆實際碰撞產生的佇列項，確認重開清除它；舊項在新局延遲到達也不得污染新牌或留下待處理資料。高處邊界案例從 y=3m 以 6m/s 分別沿 x、z 方向飛向牆，必須發生真實牆碰撞並保留薄片及所有權；不能只在地面阻擋或以截斷位置代替碰撞。

自然試玩與這些局部回歸分開記錄。曾觀察到發射出生 AABB 與既有疊牌重疊，甚至完整板厚重疊；AABB 重疊不單獨證明字形實心部分穿入，但足以作保守出生檢查。初始重疊可能讓接觸修正注入非預期能量，因此不能把這種數值爆衝造成的翻獲當作合理可玩性的證據。

發射前沿八個方向尋找牆內且 AABB 不與其他桌面枚重疊的位置，排除即將拿起的同一枚；所有候選共用原高度、平移與旋轉預算。若全被阻擋，不能先刪除舊剛體、清除命中旗標或開始回合。第十七組驗收分別以手中枚及桌面重投的完全受阻情境，確認拒絕後身份、所有權、原剛體、世界物件集合、姿態與回合不變；另驗證有可用方向時成功出生、整枚位於牆內、不與障礙重疊，且總能量仍等於原預算。

原生命周期 fixture 原先以低力度在已占據的中央直接生成攻方，會依賴新版已禁止的初始重疊。測試作者改為先以合法力度及有限空白瞄準點取得真正出手，再安排原有碰撞、捕獲與重投情境；所有原規則斷言保留。提高出生高度後，受阻 fixture 也移到同一出生高度，仍驗證原子拒絕，不把失去阻擋效果誤當成功。

## 高拋、偏心旋轉與拖曳反彈驗收

下緣握持點以原字框 (x=0,z=size/2) 定義，轉到重心主軸座標後，角動量方向取 r×v，角速取 I⁻¹(r×v) 再縮放至分配的旋轉能量。這是有界發射器的能量分配，不能宣稱為單次自由偏心衝量自然決定的唯一平移／旋轉比例。解析驗收用相同覆蓋率、不同長寬分布的兩個字形，檢查實際 Iω 與 r×v 同向、角動量非零，且兩者空中角速不同。

反彈設定範圍 [0,0.9]，預設 0.65；遊戲為薄片／桌面及薄片／薄片使用專用材料對，實驗室 defaultContactMaterial.restitution 仍為 0.1。測試透過真正滑桿 input 事件更新設定，同一初始高度落地時，高反彈的最大向上速度必須明顯提高；雙片案例暫停重力與轉動以隔離一維接觸，確認雙方交換動量且高反彈提高分離速度，再恢復世界重力。

每案開局重設預設 0.65，以免前案刻意使用的最高反彈污染睡眠 fixture。最高 0.9 下曾觀察到十秒內仍未自然睡眠／疊牌未穩；這是高反彈等待時間的實際限制，不能因此放寬最後必須停止才能捕獲的規則。

拖曳測試使用瀏覽器真正 mouse/pointer 事件及可見桌面座標。短於門檻的拖曳不生成薄片；有效拖曳產生有限箭頭與預測落點；放開後真正進入模擬並收起預覽。預測以無碰撞、無空氣阻力的拋物線終點核對，不宣稱能提前預測碰撞後的最後停點。電腦回合的同一手勢不能生成投擲。最新十九組遊戲案例與一組實際拖曳流程通過。

## 真正翹曲薄片與外緣撬動

遊戲在材質規範化後再建立翹曲模型，不修改原始實驗室／平板模型。以水平主軸座標定義 q(x,z)=0.18(x²+z²)/R²，R² 不小於字框半徑平方及最遠佔據格角點半徑平方，避免稀疏字產生過大局部曲率。最後高度 h=q−mean−a x−b z，mean 為質量加權平均，a、b 分別消去高度與 x、z 的質量交叉矩；退化單格／單列分母為零時該係數設零。

此離散模型保留 Σmh=0、Σmxh=0、Σmzh=0，讓原水平主軸仍可沿用。每格保存 lift=h，Ix、Iz 增加 Σmh²，Iy 保持原值。這是薄片質點加原格自身慣量的近似，並非彎曲凸片體積的精確慣量積分。原平面支撐凸包／能障只可作穩定參考，不能宣稱是翹曲後的精確接地能障。

碰撞分片的四個上下角點直接使用同一 h，垂直厚度保持 0.14m；水平投影不填字形孔洞。分片內表面是四角線性平面近似，對寬 w、深 d 的分片，與連續二次高度的最大插值差不超過 0.18(w²+d²)/(4R²)。可見輪廓先細分再依同一高度場翹曲，並保留原 UV；頂面必須非平面，所有新增三角形均須有繪製材料群組。

曲面回歸使用單格、單列、單行、完整矩形與非對稱「我」，檢查有限值、原模型不變、質點重心與交叉慣量、增加的主慣量，以及真正凸片角點與視覺頂點。完整矩形的外緣下方必須有可進入空隙；這不代表任何不對稱字形的每條邊都等量抬起。

獨立撬動案例以同一窄薄片在 3m/s 入射速度撞向同一完整矩形的外緣，分別比較原平板及翹曲版。世界處於未出手 ready 狀態、反彈設零，因此遊戲邊緣助推不介入；兩案均必須發生真接觸。翹曲版最大角速須超過平板三倍，重心抬升須多於 2mm。實測約 0.317 對 0.052 rad/s、5.82 對 0.18mm；這證明該幾何案例更容易撬起，不保證任意字形或任何撞擊都翻面。

接地與疊放 fixture 改為根據真正 AABB 最低點安放，避免新曲面出生即穿入地面或支撐牌；疊放在有界步數內等待真正停止，保留原支撐、捕獲與快取失效斷言。最新二十一組遊戲案例及實際拖曳流程通過，原物理／攻防保護檔保持不變。

## 睡眠支撐紀錄回歸

引擎可省略睡眠物件的接觸方程，因此「本次 contacts 中沒有桌面」不必然代表已失去支撐。只有曾沿真實接觸路徑連到桌面的薄片，才可保存支撐路徑的剛體身份、位置與姿態；不能為從未接地的空中枚建立紀錄。

沿用紀錄時，該枚必須仍在睡眠，路徑上的每個剛體必須仍屬本局桌面枚、位置及姿態未變，且線速度及角速度都低於停止門檻。開始新投擲或捕獲移除支撐時，清除剩餘桌面枚的舊支撐紀錄並喚醒它們，讓世界重新求解支撐與落下。

三組回歸直接建立真實地面或上下層接觸，不偽造 contacts 或支撐快取：

- 接地記錄後入睡，確認接觸方程確實被省略但仍可判停止；移到空中後，即使背面、零速度及強制結算，也不能捕獲。
- 兩片疊放並睡眠後，上層可沿已確認路徑判停止；正常捕獲下層時，上層必須喚醒、失效舊紀錄，不能繼續懸空判為接地。
- 新投擲必須清除前回合紀錄並喚醒所有剩餘桌面枚。

目前產品在開始對局時啟用 world.allowSleep，離開對局時關閉。第一組直接檢查產品已啟用此設定，並經真實落地及引擎自然入睡的最後一步驗證支撐紀錄；測試不再代產品開啟睡眠。這驗證睡眠策略的正確性，實際完整對局的超時改善仍應由完整試玩資料確認。

需要重新安排位置來取得新接觸的 fixture，會清除原支撐紀錄並喚醒剛體，讓引擎重新求解；保留側立必須取得真實桌面支撐的原斷言。專門測試「睡眠中被移到空中」的案例則刻意不喚醒，以驗證舊姿態紀錄自行失效，兩種情境不可混淆。
